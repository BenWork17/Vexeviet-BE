# AGENTS.md
- Stack: pnpm + Turborepo monorepo (`apps/*`, `services/*`, `packages/*`), Node >=18, TypeScript strict.
- Architecture: `apps/api-gateway` proxies to domain services (`user-service`, `route-service`, `booking-service`, `payment-service`).
- Shared libs: `packages/common` (utils/types), `packages/config` (env/config), `packages/database` (Prisma client/schema/migrations/seeds).
- Data layer: MySQL (primary, via Prisma), Redis cache, Docker Compose for local infra.
- Service pattern: Express + layered modules (route/controller -> service -> repository/db); validate input with Zod where present.
- Root dev/build: `pnpm dev`, `pnpm build`, `pnpm lint`, `pnpm type-check`, `pnpm test`.
- Docker/db: `pnpm docker:up`, `pnpm docker:down`, `pnpm prisma:generate`, `pnpm prisma:migrate`, `pnpm db:seed`.
- Integration/perf: `pnpm test:integration`, `pnpm test:perf` (k6 scenarios under `tests/performance/k6`).
- Single package commands: `pnpm --filter <workspace> <script>` (ex: `pnpm --filter @vexeviet/user-service lint`).
- Single test file (Jest packages): `pnpm --filter @vexeviet/booking-service test -- src/path/to/file.test.ts`.
- Single test name: `pnpm --filter @vexeviet/booking-service test -- -t "test name"`.
- Code style: Prettier (`singleQuote: true`, `semi: true`, `printWidth: 100`, `tabWidth: 2`, `trailingComma: es5`).
- ESLint: `@typescript-eslint` with type-aware rules; `no-explicit-any` error, floating promises error, explicit return type warn.
- Types: avoid `any`; prefer explicit DTO/domain types and typed function returns on public/service boundaries.
- Naming: kebab-case folders/files; PascalCase types/classes; camelCase variables/functions; UPPER_SNAKE_CASE constants.
- Imports: external -> workspace (`@vexeviet/*`) -> local; avoid deep relative chains when workspace alias exists.
- Async/error handling: wrap async handlers, return structured HTTP errors, never swallow errors, log with context.
- Security: never commit secrets; use `.env` (from `.env.example`); keep JWT/keys out of logs.
- Rule files check: no `.cursor/rules`, `.cursorrules`, `CLAUDE.md`, `.windsurfrules`, `.clinerules`, `.goosehints`, or `.github/copilot-instructions.md` found.
